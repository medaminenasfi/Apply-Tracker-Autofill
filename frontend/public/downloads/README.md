# Extension Download

To create the extension.zip file:

1. Navigate to the extension folder: `../../extension/`
2. Select all files in the extension folder
3. Compress/zip them into a file named `extension.zip`
4. Move the zip file to this directory: `frontend/public/downloads/extension.zip`

The extension folder contains:
- manifest.json
- popup.html
- popup.js
- content.js
- background.js
- auth-content.js
- styles.css
- README.md

After creating the zip file, users can download it from `/extension` page and install it in Chrome.
