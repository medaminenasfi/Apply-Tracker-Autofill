## What it does

Job application tracker with Kanban board, profile/CV management, Answer Vault sync, and a Chrome extension that autofills forms, ghost-saves applications, and scores job–CV match with AI.

## Highlights for resume bullets

- Built end-to-end job tracker (Kanban, notes, deadlines, 20-app free tier) with NestJS + MongoDB
- Shipped Chrome MV3 extension: autofill, ghost save, Answer Vault sync, AI match score
- Implemented JWT + Google OAuth, admin dashboard, feedback moderation
- Designed Answer Vault with cross-device sync (web + extension)
- Scaffolded Stripe billing, reminders, and V3 modules (auto-apply, interview, enterprise)
