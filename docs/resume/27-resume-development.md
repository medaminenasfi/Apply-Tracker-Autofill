## One-liner

Full-stack job search SaaS with a Chrome MV3 extension for autofill, application tracking, and AI-powered job–CV match scoring.

## Project description (2–3 sentences)

ApplyFlow is a job application tracker and autofill assistant built for students and early-career applicants. Users manage applications on a Kanban board, store reusable answers in a synced Answer Vault, and use a Chrome extension to fill forms and ghost-save jobs from major boards. The stack is Next.js, NestJS, MongoDB, Stripe, and OpenAI.

## Technical skills demonstrated

- **Frontend:** Next.js 14 (App Router), React, Zustand, Tailwind, i18n
- **Backend:** NestJS, MongoDB/Mongoose, JWT, OAuth, file uploads
- **Extension:** Chrome Manifest V3, content scripts, cross-origin API sync
- **Integrations:** Stripe subscriptions, OpenAI job analysis, Nodemailer
- **DevOps:** Docker, GitHub Actions CI

## STAR example (interview)

**Situation:** Job applicants re-type the same profile data and lose track of where they applied.

**Task:** Deliver a tracker plus browser autofill that works without storing passwords in the extension.

**Action:** Built profile/CV APIs, JWT cookie auth shared with the extension, label-based autofill selectors, and ghost-save to capture jobs before manual entry.

**Result:** End-to-end flow from signup → autofill → Kanban tracking; V1 beta-ready with extension zip and admin ops.
