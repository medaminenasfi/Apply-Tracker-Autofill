# 6. User Stories

[← Back to index](../README.md)

Format: **As a** … **I want** … **So that** … — Status in brackets.

## Authentication

- As a **guest**, I want to register with email/password, so that I can use ApplyFlow. **[DONE]**
- As a **user**, I want to log in and stay signed in via cookies, so that I don't re-auth daily. **[DONE]**
- As a **user**, I want to reset my password by email, so that I can recover my account. **[DONE]**
- As a **user**, I want to sign in with Google, so that signup is faster. **[PARTIAL]**

## Profile

- As a **user**, I want to fill my profile once, so that the extension can autofill forms. **[DONE]**
- As a **user**, I want to upload multiple CVs and pick a primary, so that autofill uses the right file. **[DONE]**
- As a **user**, I want an address field, so that location fields on forms are filled. **[DONE]**

## Answer Vault

- As a **user**, I want to save categorized answers, so that I reuse them on applications. **[DONE]**
- As a **user**, I want vault synced to the cloud, so that I use the same answers on another device. **[DONE]**
- As a **user**, I want to paste answers from the extension on job sites, so that I don't retype essays. **[DONE]**

## Application tracker

- As a **user**, I want a Kanban board, so that I see my pipeline at a glance. **[DONE]**
- As a **user**, I want to filter and search applications, so that I find one quickly. **[DONE]**
- As a **user**, I want deadline and notes on each app, so that I stay organized. **[DONE]**
- As a **Pro user**, I want unlimited applications, so that I'm not capped at 20. **[PARTIAL — cap enforced; upgrade flow needs Stripe live]**

## Extension

- As a **user**, I want one-click autofill, so that I save time. **[DONE]**
- As a **user**, I want to save the current job from the popup, so that I track without leaving the page. **[DONE]**
- As a **Pro user**, I want applications logged when I click Submit, so that I never forget to track. **[DONE — ghost save]**
- As a **Pro user**, I want a match score before applying, so that I know if my CV fits. **[DONE — Match button]**

## Reminders & analytics

- As a **user**, I want follow-up reminders, so that I check in after 7 days. **[PARTIAL — in-app only]**
- As a **user**, I want email alerts for interviews, so that I don't miss them. **[NOT DONE]**
- As a **Pro user**, I want to see which CV gets more interviews, so that I optimize. **[PARTIAL]**

## Billing

- As a **user**, I want to see pricing and upgrade, so that I can go Pro. **[PARTIAL — needs Stripe keys]**
- As a **Pro user**, I want to manage subscription in settings, so that I can cancel. **[PARTIAL]**

## Admin

- As an **admin**, I want to view users and applications, so that I monitor beta. **[DONE]**
- As an **admin**, I want to reply to feedback, so that I support users. **[DONE]**

## V3 (future)

- As a **user**, I want practice interview questions for a role, so that I prepare. **[PARTIAL — text only]**
- As a **user**, I want GitHub achievements imported, so that my resume stays current. **[PARTIAL]**
- As a **counselor**, I want a dashboard of student progress, so that I advise at scale. **[PARTIAL]**
