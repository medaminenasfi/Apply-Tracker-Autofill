## Description

ApplyFlow / PulseCV is a career command center for students and early-career professionals. It combines a web-based Kanban application tracker with a Chrome extension that autofills job forms, stores reusable answers, and progressively adds AI (match score, ghost save, reminders).

## Vision

Become the most intelligent career management platform — turning job search from repetitive grind into a fast, organized, AI-assisted process.

## Objectives

- Eliminate repetitive data entry on job application forms
- Centralize application tracking (Kanban + filters + notes)
- Introduce AI to match answers to job descriptions (V2)
- Automate application logging and follow-up reminders (V2)
- Evolve toward proactive career agent features (V3)

## Business Goals

| Phase | Goal |
|-------|------|
| V1 | Beta users (50–200); validate profile → autofill → track loop |
| V2 | Paid Pro subscribers at $5–8/month via Stripe |
| V3 | Advanced tier + enterprise/university licensing |

## Target Users

- University students (internships)
- Recent graduates (entry-level)
- Early-career professionals (0–5 years)
- Career services / counselors (V3 enterprise)

## Value Proposition

> Set up your profile once. Apply faster with autofill. Track everything on a Kanban board. Upgrade for AI match score and ghost save.

- Saves hours of repetitive typing per month
- Reduces application anxiety with visual tracking
- Affordable vs. premium competitors ($5–8/mo target)
